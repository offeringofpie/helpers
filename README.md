# @offeringofpie/helpers

Learning how to create a proper npm package.

> Work in progress. Nothing to see here (yet).

## Install

```bash
pnpm add @offeringofpie/helpers
```

## Development

```bash
pnpm install
# compile src to dist
pnpm run build
```

## Release:

```bash
pnpm release # --minor / --major for larger versioning
```
